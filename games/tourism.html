How real-time mode works

  1. The lecturer connects Supabase and creates a room for a specific class.
  2. Students open the same HTML on their own devices, connect to the same Supabase project, and enter the PIN.
  3. The lecturer starts and advances questions. Each student submits an answer from their own device.
  4. The leaderboard updates as answers are received. Group mode combines students who enter the same team name.

Important: This is a classroom prototype. A Firebase project and Realtime Database are required; this file alone cannot provide cross-device real-time communication. For graded/high-stakes use, add authenticated accounts and server-side score validation before deployment.
